# tkflow

Preserve the user's sketch and edits. Obsidian CLI is the primary live interface.
Keep the implementation local and dependency-light. Never silently fall back to
filesystem writes when the live CLI fails. Templates are product behavior.

Plan before implementation, verify observable behavior, and checkpoint logical
milestones with single-line Conventional Commits without co-authors.

Run `npm test` after behavioral changes. tkflow is distributed through native host
plugin managers; do not reintroduce a Python installer or runtime dependency.
Document live-app proof separately from isolated tests. Do not claim an empty
template is a generated blueprint or that a handoff packet is a completed audit.
